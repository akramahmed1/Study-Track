# StudyTrack – Student Pilot Checklist

**Goal:** ten students each complete the core workflows without help.
**Acceptance target:** at least **9 of 10** students complete every core task without help.

## Before the pilot

- [ ] StudyTrack opens in Chrome (Live Server or the pilot copy you were given).
- [ ] Open **Settings → Clear all StudyTrack data** so the pilot starts empty.
- [ ] Have a way to take notes. Do not ask students for real course details: they will use sample data.

## Rules for the facilitator

1. Read the introduction aloud. Do not demonstrate or hint.
2. If a student asks for help, say "Do what you would normally do." If you do give help, or the student gives up, mark that task **F** (fail).
3. Mark **P** (pass) only if the student finished the task alone.
4. Write short notes on where students hesitated. They are useful even for passes.

## Introduction to read aloud

"This is StudyTrack, a small app for keeping track of assignments. It keeps everything in this browser only. I will give you a short list of tasks. I am testing the app, not you, so there are no wrong answers. Please say out loud what you are thinking. I cannot help while you work."

## Tasks (all use sample data, no real student information)

| ID | Task given to the student | Passes when |
|---|---|---|
| T1 | "Load the sample assignments." (Settings) | Sample courses and assignments appear on the dashboard. |
| T2 | "Add a new course called your favourite subject." | The course appears in the course list. |
| T3 | "Add an assignment in that course, due tomorrow, with a reminder one hour before." | The assignment appears in the list with the correct course and due date. |
| T4 | "Show only the overdue assignments." | The Overdue filter is selected and only overdue items show. |
| T5 | "Mark one assignment as complete. What happened to the numbers?" | The assignment is Completed and the student notices the counts or progress change. |
| T6 | "Change the due date of the assignment you added." | The details show the new due date. |
| T7 | "Reopen the assignment you completed." | It is no longer Completed. |
| T8 | "Delete one assignment." | The student confirms in the dialog and the assignment is gone. |
| T9 | "Try to save a new assignment without a title. What do you see?" | The student sees the message next to the title field and nothing is saved. |
| T10 | "Where does StudyTrack keep your records? How would you find out?" | The student finds the storage note in Settings and can say the records stay in this browser. |

After the last task, the **facilitator** presses **Settings → Clear all StudyTrack data** and checks the dashboard is empty.

## Between students (shared browsers)

- [ ] Press **Settings → Clear all StudyTrack data** and confirm.
- [ ] Check the dashboard shows 0 / 0 / 0 and no courses.
- [ ] Close any leftover reminder banners.
- [ ] Reload the page.

## Optional questions after the tasks

1. What was the easiest part?
2. What was confusing?
3. Would you use this for your own coursework? Why or why not?
4. Did the reminder note ("only works while the page is open") make sense?
